# 折盒工作台 foldbench

浏览器里的折盒结构校核台:刀版编辑 → 刚性折叠求解 → 穿插校核 → 出件交付。

## 运行

```bash
pnpm install
pnpm dev
```

构建:`pnpm build`,类型检查:`pnpm typecheck`。

## 路由

- `/library` 工程库:浏览器本地存档,新建/复制/删除工程
- `/editor` 刀版编辑:面板增删、轮廓吸附、孔洞、压痕指派、插舌插槽
- `/fold` 折叠校核:三维折叠回放、折叠顺序、穿插定位、联动折角、间隙测量
- `/deliver` 交付:出件检查、冲突阻断、SVG 刀版 / OBJ 三维导出、版本对照

## 校核规则

- 面板刚性折叠,只绕压痕旋转,绝不拉伸
- 接触不算穿插:穿透深度超过纸厚才记冲突
- 插槽单边间隙 < 0.3mm 定位到具体插舌并阻断出件,改宽即解除
